# Cocos Creator 3.8.8 表现层约定（竖屏 720x1280 设计分辨率，微信小游戏）
- 逻辑全部在 assets/scripts/core/game.ts 和 config.ts（与上文相同），表现层只调用 Game 的公开方法、读取公开字段，不改规则。
- 只用 'cc' 模块：_decorator, Component, Node, Label, Graphics, Color, UITransform, Vec3, tween, Tween, Sprite, SpriteFrame, SpriteAtlas, resources, Animation, input, Input, EventTouch, UIOpacity, view, director, sys, Widget。不要用 prefab 和场景里预先摆的节点：所有节点在代码里 new Node() 创建（父节点为挂脚本的 Canvas 节点），这样只需要一个空场景 + Canvas 挂 GameRoot 即可运行。
- 占位素材：纯色块用 Graphics 画（rect+fill），文字用 Label（fontSize 24~40，中文）。
- 文件与职责：
  1. assets/scripts/ui/Art.ts：export class Art。static async preload()：尝试 resources.loadDir('art', SpriteFrame) 加载，失败不报错。static frames(name:string):SpriteFrame[] 返回 resources/art/<name>/ 下按文件名排序的序列帧（如 hero_dig/0.png..5.png），没有则空数组。static makeVisual(name:string, w:number, h:number, color:Color, label?:string):Node —— 有序列帧就建 Sprite 节点并用 schedule 按 fps=10 循环播（返回节点上 setFrames 播放），没有就建纯色块+文字占位。static play(node, name, fps, loop) 切换序列帧（无帧时 no-op）。约定的名字：hero_idle, hero_walk, hero_dig, hero_fall, box_small, box_big, glow_white, glow_blue, glow_gold, glow_rainbow, pop_flash, icon_<itemId>, bg_<locationId>, map, home_0..2, sleep_bench/diner/netcafe, npc_patrol/guard/auntie/rival/cat/courier, fortune_tube, card_day/card_fail/card_cert, ev_<eventId>。
  2. assets/scripts/ui/Fx.ts：export class Fx 纯代码缓动工具：shake(node, strength, duration)、screenShake(root)、pulse(node)、popArc(node, from:Vec3, to:Vec3, duration)（抛物线）、freeze(seconds):Promise、flash(root, color)、edgeGlow(root, color, on:boolean)、fadeIn/fadeOut、dimOverlay(root):Node、floatText(root, text, pos, color)、barTo(barNode, ratio)、vibrateShort()（调用 wx.vibrateShort，若 globalThis.wx 不存在则跳过）、rainOverlay(root):Node（像素雨，用 Graphics 画短线并循环下移）、confetti(root)。返回 Promise 的都用 tween().call(resolve)。
  3. assets/scripts/ui/LocationView.ts：export class LocationView，构造参数 (root:Node, game:Game, onChanged:()=>void, onEvent:(ev)=>void, onLeave:()=>void)；show()/hide()。显示：地点背景占位、盒子列表（小盒 32x32 比例放大到 96、大盒 144，未开的才可按）、HUD 由 GameRoot 画。长按交互：TOUCH_START 记录时间；按住每帧 update 计算秒数 → 0~1 秒盒子左右抖+碎纸片小方块飞出+首次 Fx.vibrateShort；1~3 秒抖动加剧，盒子上方 glow 色块颜色 = game.glowFor(秒, boxId)（white/blue/gold/rainbow），gold/rainbow 时 Fx.edgeGlow；底部进度条（0~maxHoldSec）和「剩余体力 X / 本次将扣 Y」；TOUCH_END/CANCEL 时调用 game.dig(boxId, 秒)：小盒走短版（鼓一下、撕开、≤1 秒）；大盒「嘭」盖弹开；result.mishap 时窜出猫色块或绿烟 + Fx.screenShake；物品依次 popArc 飞入待选区（floor 区，屏幕中部一排），稀有/史诗 freeze 0.3 秒 + flash + screenShake + 显示 quip 字幕；result.event 则调用 onEvent；result.collapsed 则 onChanged()。背包区：屏幕下部画 game.bagW x game.bagH 格子（每格 80px）。拖拽：从待选区按住物品拖到背包格上，松手时根据落点计算格坐标调用 game.placeFromFloor(uid,x,y,rotated)，成功则吸附到格子并播放「咔」（floatText），失败则格子闪红、物品 tween 回原位。双击/点击待选区物品弹出小菜单：吃掉(可吃时)/扔掉/旋转(2格)。点击背包里的物品：拿出(moveToFloor)/吃掉。按钮：「换地点」(game.leaveLocation 后 onLeave，提示地上没装的会丢)、「回家」(显示回家需 X 体力)。每次状态变化后调用 onChanged()。
  4. assets/scripts/ui/EventView.ts：export class EventView，show(root, game, ev:PendingEvent, done:()=>void)。统一节奏：Fx.dimOverlay → 像素小剧场 1~2 秒（用色块+文字表现，按名字 ev_<id> 有序列帧就用）→ 出选项按钮（ev.options）→ 调 game.resolveEvent(i, minigameWin) → 结果小动画 → done()，全程 ≤4 秒（不含玩家思考）。九种：patrol 手电光扫过（黄色三角色块从左扫到右）主角一僵（停止抖动）；礼貌离开=主角色块鞠躬（缩放y）后小碎步左移淡出；装散步=左右踱步，成功大叔挥手走（色块移出），失败大叔笑脸文字「这边请~」。guard 闸门色块从上落下「咔」。rival 两个色块对视 + 「VS」闪烁，选比赛则进入 3 秒狂点小游戏（统计点击次数 >= 15 判赢），赢=对方耸肩离开，输=主角压扁坐地。auntie 画面转暖黄 overlay，饭盒色块+热气，主角星星眼文字「★_★」，饱腹条上涨。delivery 电动车色块从右刹停（tween 快速进入后抖一下）丢袋走，字幕「这单算你的」。wallet 钱包闪光，只有「归还」一个按钮，失主鞠躬，掉「¥20」和「♥」floatText。cat 小猫从盒子后探头；喂=之后在主角脚边显示小猫色块+头顶「☆」（GameRoot 根据 game.catLuck>0 显示）；不喂=「喵」走掉。rain 由 Fx.rainOverlay 全屏雨 + 主角头顶塑料袋色块，持续到当天结束（GameRoot 根据 game.raining 维护）。夜间温情 night_warmth：export function playNightWarmth(root):Promise —— 暖色 overlay + 环卫阿姨塞包子 + 文字。
  5. assets/scripts/GameRoot.ts：@ccclass('GameRoot') export class GameRoot extends Component，挂在 Canvas 上。start() 中 await Art.preload()，new Game(Date.now()%1e9) .startGame()。常驻 HUD（顶部）：第X天、时钟 HH:MM、饱腹/体力/心情三条进度条（Fx.barTo）、金钱、「回家需 X 体力」（game.homeCost()，在家时隐藏）、签名。屏幕：加载页（「本游戏纯属虚构，现实请勿模仿」1.5 秒）→ fortune（签筒摇晃→签面文字、tier 颜色，按钮「就它了」acceptFortune、「重抽 ¥X」rerollFortune 钱不够置灰；adsEnabled=false 不显示任何广告按钮）→ map（8 个地点按钮，显示名称、移动体力 travelCost、今日剩余盒子数、签指定地点高亮、被 banned 灰叉；按钮「回家」「收工」(endDayAway)）→ travel 后进 LocationView → home（自动卖货后显示日结算卡：今日最离谱收获、收入、饱腹余量、吐槽；商店三按钮：买吃的 ¥8、扩背包 ¥40/¥90、升级落脚点；「睡觉」→ 若触发温情播 playNightWarmth → sleep()）→ collapsed（倒霉卡：spotName、丢了哪些、第二天体力，按钮「醒来」wakeUp）→ lost（失败卡「你在深圳活了 X 天」+ deathCause + 最离谱收获 + 「再来一局」+「分享」（分享仅调用 wx.shareAppMessage，没有任何奖励））→ won（「深圳生存成功」证书 + 编号（随机6位）+ 日期 + confetti）。phase 变化统一由 refresh() 根据 game.phase 切换。排行榜留 TODO 接口。
