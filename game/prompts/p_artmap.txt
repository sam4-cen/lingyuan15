## Art.ts 改动
- preload()：resources.loadDir('art', SpriteFrame) 全部加载；所有 SpriteFrame 的 texture 设置 setFilters(Texture2D.Filter.NEAREST, Texture2D.Filter.NEAREST) 保证像素清晰；有 insets 的设置 spriteFrame.insetLeft/Right/Top/Bottom。然后后台 loadBundle('bg') 并加载所有背景。
- frames(name)：先查 ART_ALIAS 解析到真实路径，再取帧（res 的 art/<path>/0..n 按数字排序；bg 单帧）；icon_<itemId> 走 ICON_MAP → art/icons/<iconName>。
- makeVisual(name,w,h,color,label)：有帧→Sprite（sizeMode CUSTOM，宽高为 w,h；有 insets 时 type=SLICED）并按 fps(默认10) 播放，loopFrom 指定循环起点；无帧→保持原来的色块+文字占位。如果是 bg 且还没加载完，先占位，加载完自动替换成 Sprite。
- 新增 static makeCard(kind:'card_day'|'card_fail'|'card_cert', parentH:number):Node：卡片按高度适配：高度 = parentH*0.7，宽 = 高*0.75，水平居中两边留空；底图为卡片素材，上面挂一个 content 子节点供写文字。
- 新增 static makeButton(text, w, h, onClick):Node 用 button 九宫格（无素材时色块），按下切 button_pressed。
- 新增 static drawCell(g:Graphics, x, y, size, state:'normal'|'hover'|'bad'|'filled')：代码画单个背包格（深色底+2px 浅色边框，hover 黄边，bad 红边）。
- 新增 static missing():string[] 返回本次运行中被请求但没有素材、走了占位的逻辑名（去重），用于报告。
保持原有公开方法签名兼容（preload/frames/makeVisual/play）。
