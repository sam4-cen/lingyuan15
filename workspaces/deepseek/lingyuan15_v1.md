# 《0元深圳15天》Demo 设计文档 v1

> 微信小游戏，题材是乐观向的城市生存挑战加环保回收。作者：小游戏（策划）。日期：2026-11-03。
> 标「⚠待测」的数值都是第 1 版的估算值，要等 DeepSeek 跑完模拟、小游戏测试实际打过之后再调。

## 01 定位

- 一句话：失业后身上 0 元，在深圳靠「翻找回收」活过 15 天，最后翻身。
- 目标：前期拉流量。单局 10 到 15 分钟，靠开盲盒的爽感，加上一张能晒的结局卡来带动传播。
- 基调：轻松、自嘲、有人情味。主角不是在卖惨，他是在做「城市寻宝 + 环保回收」的挑战。

## 02 30 秒核心循环

| 步骤 | 玩家操作 | 反馈 |
|---|---|---|
| ① 选地点 | 在深圳地图上点一个点位，每个时段只能去 1 个 | 显示要消耗的精力和预计的稀有度 |
| ② 翻找 | 点位是一个 3×3 的格子，被纸箱、袋子遮住，每点开一格消耗 1 次翻找 | 翻牌动画；稀有物品会提前抖动预告 |
| ③ 出物品 | 翻到的东西进背包，背包 12 格 | 稀有度光效和音效（见 04） |
| ④ 处理 | 对每件物品选「卖」「吃」「用」或「留着」 | 数值立刻跳动 |
| ⑤ 夜间结算 | 每天 3 个时段（上午、下午、傍晚）结束后进入夜晚，选过夜地点 | 结算卡显示当天的收获，并扣除每日消耗 |

## 04 15 天生存数值（满值都是 100，金钱除外）

| 数值 | 初始 | 每日自然消耗 | 行动消耗 | 归零后果 |
|---|---|---|---|---|
| 饱腹 | 60 | 夜间 -30 ⚠待测 | 每翻 1 格 -1 | 第二天每个时段精力 -20；连续 2 晚归零，结局「饿晕被送医」 |
| 精力 | 100 | 无，靠过夜恢复 | 移动消耗见地点表，每翻 1 格 -3 | 当天只能去过夜地点；第 2 次归零，结局「累倒了」 |
| 金钱 | 0 | 无 | 买饭：馒头 3 元饱腹 +20，快餐 12 元饱腹 +50 | 不会失败，但没钱买饭 |
| 心情 | 60 | 夜间 -10 | 被驱赶 -15 | 归零后买东西不打折、事件变差；连续 3 晚归零，结局「回老家了」 |

- 平衡目标：一个时段平均收入约 8 元，一天约 25 元，基本能填饱肚子。从第 5 天开始，靠蓝色及以上的物品攒钱。⚠待测
- 难度曲线：第 1 到 3 天新手期，掉率提高 20%；第 8 天以后会出现「同行抢点」，部分格子会被提前拿走。
- 通关结局看第 15 天的状态：

| 结局 | 条件 |
|---|---|
| 「找到工作」 | 持有招聘传单并完成面试事件 |
| 「开回收小站」 | 金钱 ≥ 800 |
| 「攒够路费，重新出发」 | 金钱 ≥ 300 |
| 「深圳活下来了」 | 其他情况 |

## 05 洗脑爆点和分享点

| 爆点 | 设计 |
|---|---|
| 出货光效 | 蓝色是一圈光；紫色加慢动作翻开；金色全屏金光、震屏，配上原创的「叮——发了！」音效 |
| 翻找节奏 | 翻一格 0.3 秒，连翻有连击音阶（do re mi……），越翻越爽 |
| 失败页 | 大字写「你在深圳活了 X 天」，下面是人生小结，比如「捡了 213 个瓶子，相当于帮地球少了 4kg 垃圾」 |
| 结局卡 | 竖版海报，有结局名、天数、最值钱的发现、环保回收量，带小程序码，适合晒朋友圈 |
| 排行 | 好友排行用微信开放数据域；全服榜按「最快攒够 800 元」和「回收量」两项排 |
| 图鉴 | 32 种物品的收集图鉴，金色物品显示全服出货率 |

**分享规范**：分享只是锦上添花，从来不是强制条件。不做「分享才能复活」「分享到群才能解锁」，不诱导分享（符合《微信小游戏运营规范》），分享按钮只放在结局卡上。

## 06 审核风险与规避

| 可能卡审的点 | 规避方式 |
|---|---|
| 吃剩饭，有卖惨和不卫生之嫌 | 全部食物改成「店家赠送的临期食品」或「花钱买的」，不出现吃别人剩下的东西 |
| 翻垃圾桶，传递负面价值观 | 统一叫「回收点、分类站」，动作叫「翻找回收」，结算里显示环保回收量 |
| 失业的消极情绪 | 开场就是「重新出发挑战」，主角乐观自嘲；所有结局都偏向正向 |
| 露宿街头，可能被认为影射社会问题 | 加入「青年驿站」（公益）选项，文案写成「城市夜游」，不写悲惨的细节 |
| 真实品牌 | 全部自创：好饱饱快餐、星点网咖、风行鞋业等，不用谐音、不用近似 Logo |
| 真实地名 | 只用片区级的泛称，不出现具体小区和企业 |
| 拾到财物不还 | 钱包、充电宝只有「归还」一个选项，归还后奖励心情和好人事件 |
| 彩票、赌博 | 只保留一张「福利彩票小奖」，不做买彩票的玩法 |
| 防沉迷 | 沿用 Boot 场景里的健康游戏忠告 |

**正能量随机事件**（每天抽 1 个，概率 ⚠待测）：好心阿姨送饭（饱腹 +30）、归还钱包后失主请吃饭并留下联系方式（指向「找到工作」线）、社工带你去青年驿站、帮小卖部搬货换 20 元、捡到流浪猫（心情 +20）。

## 07 与参考游戏《今天也在捡垃圾》的区分

| 方面 | 我们的做法 |
|---|---|
| 名字 | 《0元深圳15天》，不带「捡垃圾」字样 |
| 背景 | 真实城市深圳（泛化地名），15 天限时挑战；不照搬对方的世界观和角色 |
| 美术 | 明亮的扁平插画风，带一点暖色怀旧滤镜，沿用 shop_1998 的 LUT |
| 核心交互 | 3×3 遮盖格翻牌，加稀有度预告抖动，这是我们自己的设计 |
| 数值和物品 | 32 种物品、价格、掉率全部原创 |
| 结局 | 环保回收加翻身的多结局，再配上结局卡 |
| 文案和音效 | 全部原创，不引用对方的台词和 UI 布局 |

## 09 广告设计（目前 adsEnabled=false）

| 广告位 | 广告开启时 | 广告关闭时的兜底 |
|---|---|---|
| 失败复活 | 看视频复活，三项数值回到 50，每局 1 次 | 每局送 1 次免费「重新振作」，数值回到 30 |
| 额外翻找 | 看视频，当前点位再翻 3 格，每天 2 次 | 每天第 1 次免费 |
| 卖价翻倍 | 看视频，当天卖出的总价 ×1.5，每天 1 次 | 关闭这个广告位，不显示按钮 |
| 稀有预告 | 看视频，高亮显示格子里最稀有的那一格 | 每局免费 1 次 |

规则：第 1 天不出广告；冷却 120 秒，每天最多 8 次（沿用老花店的 AdService）。广告奖励都是可选的，不看也能通关。

## 10 Demo 范围与排期

**做 7 天，不做 15 天**。7 天就足够验证核心循环和结局卡的传播。15 天要额外做后期的难度、事件和结局分支，等 demo 数据好了再加。Demo 的结局在第 7 天按「15 天的结局条件 ×0.5」判定。

| 天 | 内容 | 负责 |
|---|---|---|
| D1 | 定稿本文档；数值配成 JSON；新图开工 | 小游戏、ui/ux |
| D2 | 地图、翻格、背包、出售 | DeepSeek |
| D3 | 数值系统、夜间结算、过夜 | DeepSeek |
| D4 | 事件、结局、结局卡、广告兜底 | DeepSeek |
| D5 | 接入美术和音效；包体优化 | DeepSeek、ui/ux |
| D6 | 自测，加上小游戏测试复测 | 测试 |
| D7 | 修 bug；岑体验；内部 demo | 全员 |

**包体**：主包 < 4MB，只放代码、Boot、地图和 UI。点位背景、立绘、物品图集放 resources 分包，每个分包也要控制在 4MB 以内，总包控制在 20MB 以内。老花店的立绘要压到每张 200KB 以内。

- [ ] 网页版和微信开发者工具里都能完整打完 7 天，控制台 0 报错。
- [ ] 所有文字里不出现 `[object`、`undefined`、`NaN`，没有截断或重叠。
- [ ] 每项数值归零都能走到对应结局；4 个结局都能被触发。
- [ ] 32 种物品都能掉落，卖、吃、用的效果和表格一致。
- [ ] 金色物品出货时有光效、震屏和音效。
- [ ] 结局卡能生成、能保存，分享按钮不是必选项。
- [ ] adsEnabled=false 时每个兜底都正常，不出现广告按钮的文字。
- [ ] 全文检查没有真实品牌、具体地名，也没有「剩饭」「垃圾桶」这类字眼。
- [ ] 主包 < 4MB，各分包 < 4MB；所有图片都正常显示。
